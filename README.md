# 🖥️ Web OS 4.1

A browser-based desktop environment built with HTML, CSS, and JavaScript.

## ✨ V4.1

### File Manager
- 📁 Create folders
- 📄 Create files
- 🔎 Search files
- ↕️ Sort by name, type, date, and size
- ✏️ Rename
- 📋 Copy
- ✂️ Cut
- 📌 Paste
- 🚚 Move files
- ☑️ Multi-select
- 🗑️ Recycle Bin
- ↩️ Undo
- ℹ️ File Properties
- 📱 Touch-friendly interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Pointer Events

## 📚 Version History
